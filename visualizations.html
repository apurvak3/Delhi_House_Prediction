🏠 Delhi House Price Prediction System

✅ Successfully implemented complete house price prediction system!

📊 Project Overview:

  • Dataset: 1000+ synthetic Delhi house records
  • Features: 11 input features, 14 engineered features
  • Model: Linear Regression with Scikit-Learn
  • Performance: R² = 0.407 (40.7% variance explained)
  • Accuracy: ±₹64.21 Lakhs average error

📈 Exploratory Data Analysis (EDA)

Comprehensive analysis showing price distributions, locality comparisons, feature correlations, and market insights across Delhi.

🎯 Model Evaluation Results

Model performance visualization including actual vs predicted prices, residual analysis, error distribution, and feature importance rankings.

🔍 Key Insights:

  • Location Premium: Connaught Place most expensive (₹280+ Lakhs avg)
  • Metro Effect: Metro connectivity adds ~₹13-15 Lakhs premium
  • Size Impact: Strong correlation (0.458) between area and price
  • Age Factor: Newer houses preferred, prices decrease ~2% per year
  • Sweet Spot: 3-bedroom houses most common and well-priced
